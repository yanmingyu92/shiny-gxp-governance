# Changelog

All notable changes to this template repository are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/);
this project uses semantic versioning for the template as a whole.

## [0.1.0] - 2026-09-28

### Added

- Initial public template release:
  - Governance template (roles, permission matrix, four control gates, asset
    ownership, continuity provisions, document change control).
  - Validation layer: platform IQ/OQ report template, per-application
    validation memo template, GxP classification rubric (exploratory /
    gxp-support / gxp-critical), RTM template.
  - QC layer: double-programming guide (R diffdf and SAS PROC COMPARE tracks,
    XPT v5 interchange, tolerance contract), QC comparison report template,
    PR checklist.
  - Decision records: ADR template plus five worked examples.
  - 21 CFR Part 11 expectation-to-mechanism mapping covering both commercial
    hosting (Posit Connect as the example) and self-hosted deployments.
